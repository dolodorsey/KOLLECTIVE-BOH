# Social Media System

## Purpose
Every active social page operates like its own media company. High output is required; filler is not.

## Required post record
Every post must have: entity, account, primary goal, content pillar, format, media, caption, CTA/destination, tags, collaborators, publish window, story support, approval state and provider receipt after publishing.

## Post goals
- ATTENTION
- AUTHORITY
- CULTURE
- PROOF
- CONVERSION
- FOMO
- COMMUNITY
- RECRUITMENT
- ANNOUNCEMENT

Use one primary goal per post.

## Default cadence
- @DOLODORSEY: 5 feed posts/day + active Stories
- GOOD TIMES: 4 feed posts/day + heavy Stories
- ICONIC LIVE: 4 feed posts/day + heavy Stories
- Other active focus brands: 3 feed posts/day + daily Stories
- Standard brand Story target: ~10 frames/day
- High-volume discovery/event pages: ~15 frames/day
- Reels: 4–7/week
- Carousels: 2–4/week
- Collabs: 1–3/week when there is real audience/stakeholder logic

## @DOLODORSEY voice law
This is a lifestyle-founder media property, not a flyer page.

Use: introspective, effortless, quotable, confident, culture-fluent, selective flex, understated humor, founder perspective, luxury/lifestyle/travel/building energy, concise observation.

Avoid: generic motivation, corporate copy, press releases, event-flyer captions, long explanations, repetitive direct selling.

Promotions must enter through Dr. Dorsey's life, access, work, relationships, taste or point of view. No automated cold DMs from @DOLODORSEY.

## Stories
Each feed post should normally receive 2–4 Story frames: tease -> share/context -> proof/interaction -> CTA. Add standalone BTS, polls, countdowns, reposts, FAQs, urgency and UGC.

## QA
Correct brand/account; approved media; real logos/faces/products; current dates/prices; no invented claims; no repeat abuse; correct CTA; provider permalink/post ID recorded.
