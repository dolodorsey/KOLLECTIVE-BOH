# Ambassador + Influencer System

## Lifecycle
source -> qualify -> score -> relationship check -> personalized outreach -> reply -> acceptance -> onboarding -> agreement/terms -> tracking code/link -> activation -> deliverables -> attribution -> rewards -> performance -> retention/referral

## Hard rules
- No individual code/link before acceptance + onboarding.
- Each entity has its own archetypes, offer, content requirements and attribution.
- Prefer verified warm/personal relationships when fit is strong.
- Outreach must say why the person fits this specific brand and what they receive.
- Every active ambassador has deliverables, dates, attribution and performance state.
- Non-response follows a bounded follow-up sequence; stop on reply/DNC.
- Regulated adult beverage programs require legal-age adult audience controls and prohibit youth targeting.

## Source of truth
Use `growth_ambassador_programs`, role profiles, talent pool/matches, outreach, members, lifecycle events, deliverables and performance tables.
