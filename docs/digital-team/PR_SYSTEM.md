# PR + Authority System

PR is always-on, evidence-first authority building.

## Workflow
readiness -> fact/evidence library -> story angle -> target outlet/contact -> personalized pitch -> follow-up -> interview prep -> placement -> amplification -> archive -> relationship nurture

## Every entity maintains
- approved public description
- founder/executive bio where relevant
- approved/restricted topics
- 3–5 active story angles
- evidence for material claims
- outlet/contact targets
- pitch queue
- placement/proof archive

## Truth law
Never invent revenue, users, partnerships, celebrity involvement, distribution, awards, funding, market leadership or performance claims. Material claims must resolve to evidence before pitching.

## Media selection
Match outlets to the entity: local, trade, culture, business, lifestyle, tech, food/beverage, entertainment, sports or community.
