# Daily Email System

## Law
Every active marketing entity has a daily email action. If sender + audience are verified, send. If not, the daily action is the exact setup/verification step required to become send-ready.

## Default cadence
- 1 marketing send/day/entity
- Starting target: 1,000 eligible contacts/day/entity unless verified sender ramp/provider constraints are lower
- Triggered lifecycle sequences can run separately with suppression/deduplication

## Rotation
Offer/conversion; product/service education; social proof; BTS/story; authority/press; event/calendar; ambassador/community; reactivation; release/announcement; founder/brand story.

## Flow
entity -> sender -> eligible audience -> DND/suppression -> offer -> content -> destination -> QA -> send -> provider receipt -> delivery/click/reply/conversion -> next segment

## Proof
A campaign is not complete because it exists or is scheduled. Record provider/campaign ID, attempted count, delivery/provider result, bounce/unsubscribe/complaint where available, click/reply/conversion and next action.

## Brand isolation
Never borrow another entity's sender, list or offer unless a canonical parent-managed route explicitly allows it.
