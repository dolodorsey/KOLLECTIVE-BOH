# Daily Marketing + Sales Checklist

Run separately for every active entity.

## Morning
- Load brand packet + current priority.
- Check replies, inbound intent, pipeline and overdue follow-up.
- Confirm social slots + Stories.
- Confirm daily email, audience and sender status.
- Check PR angle/pitch queue.
- Check ambassador outreach/onboarding/performance queue.
- Select the highest-value revenue action.

## Midday
- Publish/verify social content.
- Run policy-safe engagement.
- Send/verify email batch where route is ready.
- Execute sales follow-up/meeting/proposal actions.
- Execute qualified PR pitches/follow-ups.
- Execute ambassador outreach/follow-up/onboarding.
- Record provider receipts and replies.

## Afternoon
- Fill missed social inventory without filler.
- Advance warm sales conversations.
- Reconcile email results.
- Amplify PR/UGC/partner wins.
- Update ambassador deliverables/attribution.
- Fix one discovered conversion blocker.

## Closeout
- Revenue movement recorded.
- Social posts have provider proof.
- Email has provider evidence or exact setup blocker.
- PR queue has next actions.
- Ambassador queue has next actions.
- Every active sales opportunity has a next action/date.
- Failures have exact owner/machine fix.
- Tomorrow's top 3 actions selected.
