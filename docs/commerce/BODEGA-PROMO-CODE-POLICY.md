# BODEGA Promo Code Policy

## Scope
This policy applies only to **Bodega Bodega Bodega** and its verified Shopify store.

Canonical private source of truth:
- Supabase project: `KOLLECTIVE BOH`
- Entity: `enterprise_directory_records.entity_key = bodega-bodega-bodega`
- Metadata key: `promo_code_directory`

The exact private/internal code strings are intentionally **not stored in this public repository**.

## Staged tier

**Winback — 20%**
- Do not make this a generic public code.
- Activate only for a verified lapsed-customer segment through CRM/ecommerce automation.

## Operating rules
1. Do not publish Partner, Team, Ambassador, Employee, or Friends & Family codes.
2. Rotate any 75–80% code immediately if it appears publicly or is shared outside its intended audience.
3. Use unique ambassador/referral codes when attribution, commissions, or performance tracking matter. The shared ambassador tier is a benefit code, not the preferred attribution system.
4. Keep each brand/store isolated. Do not reuse BODEGA codes for STUSH, FĚNYX, concert merch, or any other Kollective entity.
5. No standing 100% “COMP” code. Complimentary orders should be manager-approved and handled as a controlled order/draft-order exception.
6. Public promotional codes should be campaign-specific when possible and retired after the campaign.
7. Supabase is the canonical internal directory; Shopify is the execution layer.
