## Six-point manager loop
1. TASKS — review overdue/due/blocked and pick top 3.
2. UPDATES — Done / Doing / Blocked / Need Approval / Social Due / To Contact.
3. APPROVALS — exact item + exact decision + recommendation + deadline + proof.
4. SOCIAL — asset + caption + CTA + destination + account + approval.
5. CONTACT — work real targets and log the reply/next follow-up.
6. CLOSEOUT — attach proof and set tomorrow's first move.

## Social execution contract
Exact package QA -> approval -> schedule/publish -> provider ID/permalink -> engagement follow-up -> result logged.

**No provider ID/permalink = NOT PUBLISHED.**

If provider API publishing is unavailable but the official brand account is confirmed, a human manager may manually post the exact approved package and immediately log the permalink/screenshot. Never route through a different brand account as a shortcut.
